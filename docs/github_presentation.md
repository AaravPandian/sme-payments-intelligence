# Make this portfolio project easy for recruiters to discover

## GitHub repository name

`sme-payments-intelligence`

## Short repository description (copy/paste)

Digital banking & SME payments dashboard using Python, SQLite SQL, Pandas, Streamlit and Plotly. Synthetic merchant payments, refunds, fees and payouts with automated tests.

## Suggested GitHub topics

`python`, `sql`, `pandas`, `streamlit`, `plotly`, `fintech`, `digital-banking`, `payments`, `data-analytics`, `portfolio-project`, `sqlite`

## CV bullet (once you've reviewed and can explain the work)

- Built a synthetic SME payments analytics project with Python, SQLite SQL, Pandas, Streamlit and Plotly, modelling 12,000 payment attempts across 120 fictional merchants and analysing payment success, net payment volume, refunds and settlement pipelines.

## Example interview explanation

"I built this educational portfolio project to understand how a fintech payments team could monitor merchant payment performance. I modelled four linked tables—merchants, payments, refunds and settlements—and used SQL and Pandas to calculate approval rates and net volumes. The Streamlit dashboard uses Plotly to let an analyst filter by merchant, industry and payment method, with automated checks to validate transaction and payout logic. All data is synthetic; this is not a live bank system."
